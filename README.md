# Myntra Clone

This is a clone of the Myntra online shopping platform. The project allows users to browse products, add them to the shopping bag, and view a summary of their shopping bag. It also includes a checkout option where users can place their order.

## Features
- Browse products by category (Men, Women, Kids, etc.)
- View product details including images, prices, and discounts
- Add items to the shopping bag
- View and edit shopping bag items
- Checkout and view order confirmation

## Technologies Used
- **HTML5**: Markup language for structuring the pages
- **CSS3**: Styling of the website
- **JavaScript**: Dynamic behavior and interactions
- **LocalStorage**: To store the items added to the shopping bag
- **GitHub**: Version control and hosting

## Setup
1. Clone this repository:
    ```bash
    git clone https://github.com/YOUR_USERNAME/myntra-clone.git
    ```

2. Navigate to the project directory:
    ```bash
    cd myntra-clone
    ```

3. Open the project in your preferred code editor.

4. Open `index.html` in your browser to view the website.

## File Structure
- **images/**: Folder containing product images
- **data/**: Folder containing product data (`items.js`)
- **css/**: Folder containing the stylesheets (`index.css`, `bag.css`)
- **scripts/**: Folder containing JavaScript files (`index.js`, `bag.js`)
